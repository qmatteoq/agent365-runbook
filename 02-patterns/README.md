# Patterns

Cross-cutting guidance that applies to more than one scenario. Where a runbook needs one of these,
it links here rather than repeating it.

These patterns cover all four scenarios, including app-only S2S, and apply to both skill-led and manual onboarding. They describe identity and token requirements independently of the editor or assistant we use.

## Currently available patterns

| Pattern | What it covers | Status |
| --- | --- | --- |
| [Choosing Your Onboarding Path](Choosing-Your-Onboarding-Path.md) | How to decide between user OBO, custom engine OBO, AI teammate and S2S | ✅ Written |
| [Token chains by onboarding path](The-Three-Token-Chains.md) | What token each path acquires, from which authority, for which audience | ✅ Written |

## Wrapping up

After choosing the identity path, use the [scenario index](../01-scenarios/README.md) to open its skill-led or manual runbook. Changing authoring routes does not change the required token chain.
